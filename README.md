# Agency Compliance Dashboard

داشبورد عربي لمتابعة مستندات والتزامات وكالة دعاية وإعلان.

## المميزات الحالية

- متابعة انتهاء الإقامات، العقود، التأمينات، التراخيص، الصيانة، والاشتراكات.
- حساب الحالة تلقائيا حسب تاريخ الانتهاء.
- بحث وفلاتر حسب النوع والحالة والمسؤول.
- إضافة سجل جديد.
- تسجيل تجديد مع الاحتفاظ بالسجل السابق.
- تسجيل دخول وربط البيانات بقاعدة Supabase.
- حفظ محلي احتياطي عند عدم توفر الاتصال.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح.

## الربط

إعدادات Supabase موجودة في `config.js`.
